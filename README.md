# Vellum^2^

*Adapted from the theme Vellum by [Cebor](https://github.com/cebor).  Sorry, but the 'attention to detail' part made me lol as there's a ton of waste and unecessary duplication in this theme, nice as it looks.*

**A multilingual Hugo theme that sets every page as an engineering drawing sheet** - featuring elements that hark back to the days of hand-drawn engineering and design documents, some of which I remember seeing in my dad's work as I would visit his office.

The irony of the original creator of this theme using AI to build the mess of the theme that they had meant I would spend hours cleaning up the code, removing TONS of arbitrary and nonsensical vibe-coded comments that bloated the project as well as consolidating a huge amount of template files to make it actually workable.

As I'm not bilingual, I removed that feature too.

The theme was orginally built for technical writing that is mostly code. I modified this to make it more into a blog/asset site - so that I could post blog entries that featured images, along with sections for specific purposes (like music I have produced) and keep it within the 'design document' style.

There was nearly 1000 lines of guff in the original README.  So far I've cut it to 25.  I reckon I'll hit around 100 when it's complete.
